# Project status

Last updated: 2026-11-09

This page separates confirmed progress from proposed design choices.

## Confirmed / reported

- The TRILINGO concept is a physical picture-button communication device.
- The intended languages are Moroccan Darija, French and English.
- An ESP32 development board has arrived.
- A 3×3 arrangement of nine picture buttons has been discussed as the current interface concept.

## Proposed / selected, but implementation not verified

- DFPlayer Mini audio module.
- 3 W, 8 Ω rectangular speaker.
- JST-PH 2.0 speaker connector.
- A three-position language selector.
- Offline prerecorded audio playback.

## Not yet verified or completed

- Exact ESP32 board model and pinout.
- Final button wiring and GPIO assignments.
- Audio-module availability and working audio path.
- Battery and charging/protection circuit.
- Final enclosure dimensions and CAD assembly.
- Custom PCB (may not be necessary for the first prototype).
- Working firmware and test results.
- Testing with intended users under appropriate adult supervision.
