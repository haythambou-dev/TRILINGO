# Mechanical design

Add the native CAD assembly file and the actual exported STEP files here.

Suggested organization:
- `assembly/`: native assembly source (.f3d, .FCStd, or documented Onshape link)
- `parts/`: native part files
- `step/`: STEP exports for each modeled part
- `renders/`: clearly labeled concept renders and final CAD screenshots

Do not label a concept render as a completed CAD assembly.
